# FUTURE_DS_01

## Sales Performance Dashboard using Power BI

The project focuses on creating an interactive **Sales Performance Dashboard using Microsoft Power BI** to analyze sales data and present important business information through visualizations and interactive filters.

---

## 📌 Project Overview

The Sales Performance Dashboard provides a visual representation of sales performance across different product categories, customer segments, and other available dimensions in the dataset. The dashboard is designed to make sales data easier to understand and helps users identify important patterns and differences in sales performance. It enables decision makers to monitor business performance, identify key profits, and uncover areas needing improvement.

---

## 🎯 Problem Statement

Businesses generate large amounts of sales data, but raw data can be difficult to analyze and interpret.

The objective of this project is to transform sales data into an interactive Power BI dashboard that allows users to:

- Analyze overall sales performance
- Compare sales across different product categories
- Analyze different customer segments
- Identify products with higher sales
- Understand sales trends and patterns
- Present business information in an easy-to-understand visual format

---

## 🛠️ Tools Used

- **Microsoft Power BI** – Dashboard development and data visualization
- **Power Query** – Data preparation and transformation
- **DAX** – Calculations and measures
- **GitHub** – Project documentation and version control

---

## 📊 Dashboard Features

The dashboard includes:

- Interactive **Customer Segment** selection
- Sales analysis by **Product Name**
- Sales analysis by **Product Category**
- Visual comparison of sales performance
- Interactive charts and graphs
- KPI and summary visuals
- Easy-to-understand dashboard layout
- Interactive filtering for exploring the data

---

## 📈 Key Performance Indicators (KPIs)

| **Metric** | **Value** | **Description** |
| ---------- | --------- | --------------- |
| **Total Sales** | **1.16M** | Total sales generated for the selected Consumer segment |
| **Top Sales Region** | **West** | Region generating the highest sales |
| **Top Sales Category** | **Technology** | Category contributing the highest sales |
| **Best Sales Year** | **2017** | Year with the highest sales performance |
| **Selected Customer Segment** | **Consumer** | Customer segment currently selected in the dashboard |

---

## 🔍 Key Insights

The dashboard helps users understand:

- Which products contribute more to overall sales.
- How sales performance differs across customer segments.
- Which product categories have stronger sales performance.
- Differences in sales across various regions and segments.
- Overall sales patterns through visual analysis.

The interactive filters allow users to explore the dashboard from different perspectives and obtain more specific insights.

---

## ▶️ How to Use

1. Download the `FUTURE_DS_01.pbix` file from this repository.
2. Open the file using **Microsoft Power BI Desktop**.
3. Explore the dashboard visuals.
4. Use the available filters and customer segment buttons to interact with the dashboard.
5. Select different segments or categories to analyze the corresponding sales performance.
